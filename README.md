# خرائط سوريا — Syria Maps

إضافة مجتمعية مفتوحة المصدر لتطبيق **OsmAnd** الرسمي، تضيف طبقات خرائط سورية
(خدمات عامة، إشعارات مرور وسلامة موثقة، طبقات مجتمعية) **دون تعديل OsmAnd أو إعادة توزيعه**.

> English: [README.en.md](README.en.md)

>  **تنبيه مهم:** البيانات الموجودة حالياً في المستودع **اصطناعية (تجريبية) بالكامل** لأغراض التطوير،
> وكل عنصر منها يحمل العلامة `synthetic: true` وكلمة «تجريبي/اصطناعية» في اسمه. لا تمثل أي منشأة حقيقية.

## الرؤية

خريطة سورية يبنيها المجتمع: أسماء عربية دقيقة للشوارع والأحياء، نقاط خدمات عامة محدثة،
وإشعارات طرق موثقة المصدر. كل ذلك ضمن OsmAnd الذي يعمل دون اتصال.

## الحالة الحالية

| الميزة | الحالة |
|---|---|
| خادم FastAPI + PostgreSQL/PostGIS عبر Docker Compose |  منفّذ (لم يُشغّل Docker على جهاز المطوّر، يُختبر في CI) |
| واجهة بيانات الطبقات، الاستعلامات المكانية، التقسيم إلى صفحات، التحقق من المدخلات | منفّذ ومختبَر |
| طبقة الخدمات العامة (بيانات اصطناعية) |  منفّذ |
| بلاطات PNG شفافة تعمل كمصدر خرائط أونلاين في OsmAnd |  منفّذ |
| حزمة `.osf` (إضافة + أيقونة + مصدر بلاطات + ملف GPX للعمل دون اتصال) |  منفّذ ومتحقَّق بنيوياً —  **لم تُجرَّب على جهاز Android حقيقي بعد** |
| تنزيل البيانات بصيغة GeoJSON و GPX مع رقم الإصدار |  منفّذ |
| إشعارات المرور والسلامة (الموثقة فقط) |  النموذج والواجهة جاهزان — **لا يوجد مصدر بيانات معتمد بعد** |

| حركة مرور لحظية |  مخطط — يحتاج مزوّد بيانات حقيقي |
| مساهمات المستخدمين مع الإشراف |  مخطط |

## كيف يعمل؟ (باختصار)

حزمة `.osf` في OsmAnd هي **ملف ZIP للبيانات فقط** ولا يمكنها تشغيل أي كود.
لذلك يقوم الخادم بكل المعالجة، ويصل الناتج إلى OsmAnd عبر آليات رسمية:

1. **مصدر خرائط أونلاين** (`MAP_SOURCES`) يشير إلى `https://خادمك/tiles/public-services/{0}/{1}/{2}.png`؛
   البلاطات تُرسم من قاعدة البيانات مباشرة، فتصل التحديثات دون إعادة تثبيت (تنتهي صلاحية الذاكرة المؤقتة بعد 60 دقيقة).
2. **ملف GPX** داخل الحزمة يحتوي نقاط الطبقة للعمل **دون اتصال** (لقطة ثابتة لإصدار معين).
3. خرائط OsmAnd الأساسية لسوريا تبقى من مدير التنزيل في OsmAnd نفسه.

التفاصيل: [docs/feasibility.md](docs/feasibility.md) و [docs/architecture.md](docs/architecture.md).

## التثبيت والاستخدام في OsmAnd

### 1. التثبيت

1. ثبّت OsmAnd من Google Play.
2. نزّل `syria-maps.osf` من خادمك: `https://ur-Server/osmand/syria-maps.osf`
   (أو من صفحة الإصدارات على GitHub).
3. افتح الملف بـ OsmAnd ← «استيراد» وأكّد الاستيراد.

> **مهم:** رابط البلاطات مكتوب داخل ملف `.osf`. الملف المبني محلياً في مجلد `dist` يشير إلى العنوان
> المثالي `maps.example.org` ولن يعمل. استخدم دائماً الملف المنزّل من خادمك، أو ابنِه بعنوان خادمك
> (`build-osf --base-url https://ur-Server`).

### 2. التأكد من نجاح الاستيراد

- **القائمة ← الإضافات (Plugins):** يجب أن تظهر إضافة **Syria Maps / خرائط سوريا** بأيقونة خضراء.
- في القائمة نفسها فعّل إضافة **Online maps (الخرائط عبر الإنترنت)** — بدونها لا تظهر الطبقة.

### 3. إظهار الطبقة على الخريطة

1. **تهيئة الخريطة (Configure map) ← طبقة علوية (Overlay map)**.
2. اختر `Syria Maps - Public services (synthetic)`.
3. اضبط الشفافية بالشريط الذي يظهر أسفل الشاشة.
4. انتقل إلى دمشق (حوالي 33.45 شمالاً، 36.20 شرقاً) وقرّب إلى مستوى 12 أو أكثر.
   ستظهر نقاط ملونة: الأحمر مستشفى، الأخضر صيدلية، الأصفر مدرسة، البنفسجي محطة وقود،
   الأزرق موقف حافلات، الرمادي موقف سيارات. توجد مجموعات أخرى قرب حلب وحمص واللاذقية.
   **هذه النقاط تجريبية وليست أماكن حقيقية.**

البلاطات تُرسم من قاعدة بيانات الخادم، ويعيد OsmAnd تحميلها كل 60 دقيقة، فتصل التحديثات دون إعادة الاستيراد.

### 4. النقاط للعمل دون اتصال

- **أماكني (My places) ← المسارات (Tracks)** ← `syria-maps-public-services`.
- افتحه وفعّل «إظهار على الخريطة». هذه النقاط تعمل حتى في وضع الطيران.
- هذه لقطة ثابتة لإصدار البيانات وقت التنزيل؛ للتحديث نزّل ملف `.osf` جديداً
  أو ملف GPX من `https://ur-Server/api/v1/datasets/public-services/download?format=gpx`.

### 5. إذا لم تظهر النقاط

افتح هذا الرابط في متصفح الهاتف؛ يجب أن تظهر صورة فيها نقاط ملونة:

```
https://ur-Server/tiles/public-services/12/2459/1643.png
```

- إذا لم تظهر الصورة: تأكد أن الخادم يعمل (`/health`) وأن HTTPS مضبوط (Caddy أو nginx، انظر [docs/deployment.md](docs/deployment.md)).
- إذا ظهرت الصورة لكن ليس في OsmAnd: تأكد من تفعيل Online maps واختيار الطبقة العلوية، ومن أن
  `SYRIA_MAPS_PUBLIC_BASE_URL` في ملف `.env` على الخادم هو عنوان HTTPS الصحيح، ثم نزّل ملف `.osf` من جديد.

### بديل بدون `.osf`

الرابط الذي يعيده `GET /osmand/add-tile-source/public-services` يضيف مصدر البلاطات مباشرة عند فتحه على الهاتف.

قائمة التحقق على الجهاز وحالة التحقق: [docs/osmand-integration.md](docs/osmand-integration.md).

## إعداد بيئة التطوير

### مع Docker

```bash
cp .env.example .env
docker compose up -d --build
curl http://localhost:8000/health
```

التوثيق التفاعلي: http://localhost:8000/docs

### بدون Docker (تخزين في الذاكرة)

```powershell
powershell -ExecutionPolicy Bypass -File scripts\dev.ps1
```

### الاختبارات وبناء الحزمة

```bash
cd backend
pip install -r requirements-dev.txt
pytest                                   # اختبارات PostGIS تعمل عند ضبط TEST_DATABASE_URL
python -m app.cli build-osf --storage memory --base-url https://maps.example.org
python -m app.cli validate-osf ../dist/syria-maps.osf
```

## هيكل المستودع

```
backend/     خادم FastAPI، أدوات CLI، الاختبارات
database/    ملفات الترحيل SQL والبيانات التجريبية
layers/      تعريف كل طبقة في ملف YAML (لإضافة طبقة لا حاجة لتعديل الكود)
osmand/      توثيق الحزمة ومثال items.json
docs/        التوثيق التقني
examples/    إعدادات Caddy/nginx وأمثلة طلبات
scripts/     سكربتات التطوير والبناء
```
