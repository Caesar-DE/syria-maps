# خرائط سوريا — Syria Maps

إضافة مجتمعية مفتوحة المصدر لتطبيق **OsmAnd** الرسمي، تضيف طبقات خرائط سورية
(خدمات عامة، إشعارات مرور وسلامة موثقة، طبقات مجتمعية) **دون تعديل OsmAnd أو إعادة توزيعه**.

> English: [README.en.md](README.en.md)

> **تنبيه مهم:** البيانات الموجودة حالياً في المستودع **اصطناعية (تجريبية) بالكامل** لأغراض التطوير،
> وكل عنصر منها يحمل العلامة `synthetic: true` وكلمة «تجريبي/اصطناعية» في اسمه. لا تمثل أي منشأة حقيقية.

## الرؤية

خريطة سورية يبنيها المجتمع: أسماء عربية دقيقة للشوارع والأحياء، نقاط خدمات عامة محدثة،
وإشعارات طرق موثقة المصدر. كل ذلك ضمن OsmAnd الذي يعمل دون اتصال.

## الحالة الحالية

| الميزة | الحالة |
|---|---|
| خادم FastAPI + PostgreSQL/PostGIS عبر Docker Compose | منفّذ (لم يُشغّل Docker على جهاز المطوّر، يُختبر في CI) |
| واجهة بيانات الطبقات، الاستعلامات المكانية، التقسيم إلى صفحات، التحقق من المدخلات | منفّذ ومختبَر |
| طبقة الخدمات العامة (بيانات اصطناعية) | منفّذ |
| بلاطات PNG شفافة تعمل كمصدر خرائط أونلاين في OsmAnd | منفّذ |
| حزمة `.osf` (إضافة + أيقونة + مصدر بلاطات + ملف GPX للعمل دون اتصال) | منفّذ ومتحقَّق بنيوياً — **لم تُجرَّب على جهاز Android حقيقي بعد** |
| تنزيل البيانات بصيغة GeoJSON و GPX مع رقم الإصدار | منفّذ |
| إشعارات المرور والسلامة (الموثقة فقط) | النموذج والواجهة جاهزان — **لا يوجد مصدر بيانات معتمد بعد** |
| استيراد الخدمات من OpenStreetMap مع تفضيل الأسماء العربية | منفّذ ومجرَّب (حوالي 11,400 نقطة)، الاستيراد على الخادم يدوي |
| بلاطات نقطية للعمل دون اتصال (`.sqlitedb`) | مخطط |
| المباني ثلاثية الأبعاد | مخطط (عبر تحسين بيانات OSM؛ حزمة `.osf` لا تستطيع حقن هندسة ثلاثية الأبعاد) |
| حركة مرور لحظية | مخطط — يحتاج مزوّد بيانات حقيقي |
| مساهمات المستخدمين مع الإشراف | مخطط |
| تطبيق أندرويد مرافق (Kotlin) يضيف طبقات النقاط إلى OsmAnd بزر واحد | منفّذ؛ جُرِّب على هاتف حقيقي مع OsmAnd 5.4.11 (النقاط تظهر على الخريطة). تسليم حزمة `.osf` لم يُجرَّب بعد |

## كيف يعمل؟ (باختصار)

حزمة `.osf` في OsmAnd هي **ملف ZIP للبيانات فقط** ولا يمكنها تشغيل أي كود.
لذلك يقوم الخادم بكل المعالجة، ويصل الناتج إلى OsmAnd عبر آليات رسمية:

1. **مصدر خرائط أونلاين** (`MAP_SOURCES`) يشير إلى `https://ur-Server/tiles/public-services/{0}/{1}/{2}.png`؛
   البلاطات تُرسم من قاعدة البيانات مباشرة، فتصل التحديثات دون إعادة تثبيت (تنتهي صلاحية الذاكرة المؤقتة بعد 60 دقيقة).
2. **ملف GPX** داخل الحزمة يحتوي نقاط الطبقة للعمل **دون اتصال** (لقطة ثابتة لإصدار معين).
3. خرائط OsmAnd الأساسية لسوريا تبقى من مدير التنزيل في OsmAnd نفسه.

التفاصيل: [docs/feasibility.md](docs/feasibility.md) و [docs/architecture.md](docs/architecture.md).

## التثبيت والاستخدام في OsmAnd

### 1. التثبيت

1. ثبّت OsmAnd من Google Play.
2. نزّل `syria-maps.osf` من خادمك: `https://ur-Server/osmand/syria-maps.osf`
   (أو من صفحة الإصدارات على GitHub).
3. افتح الملف بـ OsmAnd ← «استيراد» وأكّد الاستيراد.

> **مهم:** رابط البلاطات مكتوب داخل ملف `.osf`. الملف المبني محلياً في مجلد `dist` يشير إلى العنوان
> المثالي `maps.example.org` ولن يعمل. استخدم دائماً الملف المنزّل من خادمك، أو ابنِه بعنوان خادمك
> (`build-osf --base-url https://ur-Server`).

### 2. التأكد من نجاح الاستيراد

- **القائمة ← الإضافات (Plugins):** يجب أن تظهر إضافة **Syria Maps / خرائط سوريا** بأيقونة خضراء.
- في القائمة نفسها فعّل إضافة **Online maps (الخرائط عبر الإنترنت)** — بدونها لا تظهر الطبقة.

### 3. إظهار الطبقة على الخريطة

1. **تهيئة الخريطة (Configure map) ← طبقة علوية (Overlay map)**.
2. اختر `Syria Maps - Public services (synthetic)`.
3. اضبط الشفافية بالشريط الذي يظهر أسفل الشاشة.
4. انتقل إلى دمشق (حوالي 33.45 شمالاً، 36.20 شرقاً) وقرّب إلى مستوى 12 أو أكثر.
   ستظهر نقاط ملونة: الأحمر مستشفى، الأخضر صيدلية، الأصفر مدرسة، البنفسجي محطة وقود،
   الأزرق موقف حافلات، الرمادي موقف سيارات. توجد مجموعات أخرى قرب حلب وحمص واللاذقية.
   **هذه النقاط تجريبية وليست أماكن حقيقية.**

البلاطات تُرسم من قاعدة بيانات الخادم، ويعيد OsmAnd تحميلها كل 60 دقيقة، فتصل التحديثات دون إعادة الاستيراد.

### 4. النقاط للعمل دون اتصال

- **أماكني (My places) ← المسارات (Tracks)** ← `syria-maps-public-services`.
- افتحه وفعّل «إظهار على الخريطة». هذه النقاط تعمل حتى في وضع الطيران.
- هذه لقطة ثابتة لإصدار البيانات وقت التنزيل؛ للتحديث نزّل ملف `.osf` جديداً
  أو ملف GPX من `https://ur-Server/api/v1/datasets/public-services/download?format=gpx`.

### 5. إذا لم تظهر النقاط

افتح هذا الرابط في متصفح الهاتف؛ يجب أن تظهر صورة فيها نقاط ملونة:

```
https://ur-Server/tiles/public-services/12/2459/1643.png
```

- إذا لم تظهر الصورة: تأكد أن الخادم يعمل (`/health`) وأن HTTPS مضبوط (Caddy أو nginx، انظر [docs/deployment.md](docs/deployment.md)).
- إذا ظهرت الصورة لكن ليس في OsmAnd: تأكد من تفعيل Online maps واختيار الطبقة العلوية، ومن أن
  `SYRIA_MAPS_PUBLIC_BASE_URL` في ملف `.env` على الخادم هو عنوان HTTPS الصحيح، ثم نزّل ملف `.osf` من جديد.

### بديل بدون `.osf`

الرابط الذي يعيده `GET /osmand/add-tile-source/public-services` يضيف مصدر البلاطات مباشرة عند فتحه على الهاتف.

قائمة التحقق على الجهاز وحالة التحقق: [docs/osmand-integration.md](docs/osmand-integration.md).

## مصادر البيانات: من أين تأتي الأماكن؟

المصدر الأساسي للبيانات الحقيقية هو **OpenStreetMap (OSM)**: قاعدة بيانات خرائط مفتوحة يحررها متطوعون،
ترخيصها ODbL ويُسمح بإعادة استخدامها مع ذكر المصدر «© OpenStreetMap contributors».
يحتوي المشروع على أداة تستخرج نقاط الخدمات العامة داخل حدود سوريا فقط وتفضّل الأسماء العربية (`name:ar`).

عند التجربة (تشرين الثاني 2026) استخرجت الأداة حوالي **11,400 نقطة**: مدارس، صيدليات، مستشفيات، عيادات،
محطات وقود، مواقف، مراكز شرطة وإطفاء، مكاتب بريد وجامعات. حوالي نصفها له اسم عربي.

### الخطوة 1: الاستخراج (على جهاز الكمبيوتر)

يُفضَّل تنفيذه على جهازك وليس داخل Docker على الخادم، لأن بعض الخوادم لا تسمح للحاويات بالوصول إلى الإنترنت.

```powershell
cd "C:\OsmAnd Plugin\syria-maps\backend"
.\.venv\Scripts\python.exe -m app.cli osm-extract --output ..\dist\osm-public-services.geojson
.\.venv\Scripts\python.exe -m app.cli validate-dataset ..\dist\osm-public-services.geojson
```

يستغرق الاستخراج حوالي دقيقة. نتيجة الفحص يجب أن تكون `0 errors`. التحذيرات `feature has no name` طبيعية:
هي أماكن موجودة في OSM بدون اسم.

### الخطوة 2: نقل الملف إلى الخادم

```powershell
scp "C:\OsmAnd Plugin\syria-maps\dist\osm-public-services.geojson" root@ur-Server:/root/
```

### الخطوة 3: الاستيراد في قاعدة البيانات (على الخادم)

```bash
cd /srv/syria-maps
docker compose run --rm -v /root/osm-public-services.geojson:/data.geojson:ro migrate python -m app.cli import /data.geojson
```

النتيجة المتوقعة: `imported osm-public-services.geojson: new version 1`.

### الخطوة 4: في OsmAnd

نزّل ملف `.osf` من خادمك مرة أخرى واستورده، ثم اختر الطبقة العلوية
`Syria Maps - Public services from OpenStreetMap`.

### التحديث

كرر الخطوات 1 إلى 3 كل شهر مثلاً. الاستيراد يحدّث الأماكن المتغيرة ويحذف الأماكن التي أُزيلت من OSM،
ولا يُنشئ إصداراً جديداً إلا إذا تغيرت البيانات فعلاً. البلاطات في OsmAnd تتحدث تلقائياً، ولا حاجة لملف `.osf` جديد.

### مصادر أخرى

أي مجموعة بيانات أخرى يجب أن يكون ترخيصها يسمح بإعادة النشر. **لا تُنسخ بيانات من Google Maps أو مصادر تجارية.**
طريقة إضافة طبقة جديدة: [docs/adding-layers.md](docs/adding-layers.md).

## كيف يضيف الناس أماكن جديدة؟

### الطريقة 1 (الموصى بها): الإضافة في OpenStreetMap

كل مكان يُضاف في OSM يصل إلى طبقتنا عند الاستيراد التالي، ويصل أيضاً إلى خرائط OsmAnd الرسمية لكل المستخدمين
بعد تحديث الخرائط القادم.

1. أنشئ حساباً مجانياً على https://www.openstreetmap.org
2. أضف المكان بإحدى هذه الطرق:
   - **من داخل OsmAnd:** فعّل إضافة **OpenStreetMap Editing**، ثم اضغط مطولاً على الخريطة في مكان المنشأة ←
     «إنشاء نقطة اهتمام (POI)» ← اختر النوع (مثلاً صيدلية) واكتب الاسم ← ارفعها بحساب OSM.
   - **من المتصفح:** افتح openstreetmap.org، ثم اضغط «تعديل» (المحرر iD).
   - **تطبيقات للهاتف:** StreetComplete أو Every Door أو Vespucci.
3. اكتب الاسم العربي في الحقل `name:ar` إن أمكن، والإنجليزي في `name:en`.

الأنواع التي تقرأها طبقتنا:

| النوع | الوسم في OSM |
|---|---|
| مستشفى | `amenity=hospital` |
| عيادة | `amenity=clinic` |
| صيدلية | `amenity=pharmacy` |
| مدرسة | `amenity=school` |
| جامعة | `amenity=university` |
| محطة وقود | `amenity=fuel` |
| موقف حافلات | `highway=bus_stop` |
| محطة حافلات | `amenity=bus_station` |
| موقف سيارات | `amenity=parking` |
| مركز شرطة | `amenity=police` |
| مركز إطفاء | `amenity=fire_station` |
| مكتب بريد | `amenity=post_office` |

**قواعد OSM:** أضف فقط أماكن حقيقية تعرفها على أرض الواقع، ولا تنسخ من Google Maps أو خرائط أخرى محمية بحقوق.

### الطريقة 2: طبقة مجتمعية جديدة عبر GitHub

لبيانات لا تناسب OSM أو لطبقة مستقلة (مثلاً نقاط مياه الشرب): ملف YAML وملف GeoJSON يُرسلان كـ Pull Request.
الشرح الكامل: [docs/adding-layers.md](docs/adding-layers.md).

### غير متوفر بعد

إضافة الأماكن مباشرة من التطبيق أو الموقع إلى خادمنا، مع مراجعة من المشرفين، **غير منفّذة بعد**
(مخطط لها في المرحلة 3، انظر [docs/roadmap.md](docs/roadmap.md)).

## تطبيق أندرويد المرافق (الطريقة الأسهل)

بدلاً من استيراد الحزمة واختيار الطبقات يدوياً، يوجد تطبيق أندرويد بسيط في مجلد `android/` (بالعربية والألمانية والإنكليزية):

1. ثبّت OsmAnd، ثم ثبّت تطبيق «خرائط سوريا» (`app-release.apk`).
2. عند أول فتح يظهر معالج إعداد قصير: اللغة، والمظهر (فاتح أو داكن)، وعنوان خادمك، ثم فحص OsmAnd. يمكن فتحه لاحقاً من زر الإعدادات (الترس).
3. فعّل المفتاح بجانب الطبقة التي تريدها. تُرسل النقاط مباشرة إلى خريطة OsmAnd.
4. اضغط «فتح في OsmAnd».

ملاحظات:
- إذا رفض OsmAnd الطلب، يظهر زر «السماح لخرائط سوريا في OsmAnd». يجب السماح للتطبيقات المتصلة مرة واحدة. في OsmAnd 5.4 لا توجد شاشة إذن بعد:
  افتح OsmAnd ← القائمة ← الإضافات (Plugins)، ثم شغّل «خرائط سوريا» في القائمة.
- يحتفظ OsmAnd بهذه النقاط في الذاكرة فقط، فتختفي إذا أُغلق OsmAnd بالكامل. افتح تطبيق «خرائط سوريا» مرة أخرى فيُعيد إرسالها تلقائياً.
- طبقات الصور (Raster) لا يمكن تفعيلها عن طريق التطبيق. زر «تثبيت حزمة الخرائط» يفتح شاشة الاستيراد في OsmAnd لتؤكدها بنفسك.

البناء والتوقيع والقيود وحالة التحقق: [docs/android-companion.md](docs/android-companion.md).
التطبيق مرخّص بـ GPL-3.0 لأنه يستخدم واجهة OsmAnd الرسمية (AIDL) المرخّصة بـ GPL-3.0.

## إعداد بيئة التطوير

### مع Docker

```bash
cp .env.example .env
docker compose up -d --build
curl http://localhost:8000/health
```

التوثيق التفاعلي: http://localhost:8000/docs

### بدون Docker (تخزين في الذاكرة)

```powershell
powershell -ExecutionPolicy Bypass -File scripts\dev.ps1
```

### الاختبارات وبناء الحزمة

```bash
cd backend
pip install -r requirements-dev.txt
pytest                                   # اختبارات PostGIS تعمل عند ضبط TEST_DATABASE_URL
python -m app.cli build-osf --storage memory --base-url https://maps.example.org
python -m app.cli validate-osf ../dist/syria-maps.osf
```

## هيكل المستودع

```
backend/     خادم FastAPI، أدوات CLI، الاختبارات
database/    ملفات الترحيل SQL والبيانات التجريبية
layers/      تعريف كل طبقة في ملف YAML (لإضافة طبقة لا حاجة لتعديل الكود)
osmand/      توثيق الحزمة ومثال items.json
docs/        التوثيق التقني
examples/    إعدادات Caddy/nginx وأمثلة طلبات
scripts/     سكربتات التطوير والبناء
```
